# Design House — room-by-room redesign studio

A web app for redesigning a home one room at a time. Enter an address to pull
real public-record house facts, build a room list, add an optional "before" photo
of each room (kept on your device), generate photorealistic AI redesigns, refine
them with text edits, and print a build report (paint, wood/flooring, furniture,
notes) for a contractor.

Deployed on Vercel; state lives in your browser.

## Architecture

- **Client-owned state.** Your project (address, beds/baths, rooms, design specs)
  is stored in the browser's `localStorage` — nothing is stored on a server.
- **Source photos are local-only.** You pick a local image; it stays in the
  browser as the "before" reference and is never uploaded anywhere.
- **Keyless image generation.** Redesigns are generated by
  [Pollinations](https://pollinations.ai) (Flux), fetched **directly from the
  browser** — no API key, no server call, no function-timeout limits.
- **Thin server.** One keyed, stateless function: the house lookup
  (`/api/lookup`, RentCast). Plus `/api/config`.

## Features
- **Fetch facts** — enter an address → real beds/baths/sqft/year from public
  records (RentCast) → auto-builds the room list.
- **Room tabs** (add / rename / delete freely).
- **Choose local photo** per room — your "before", kept entirely on your device.
- **Generate / Regenerate / Apply change** — real redesigns via Pollinations (Flux).
- **Download** any redesign.
- **Design spec** per room (style, wall/trim paint + hex, flooring, wood, furniture, notes).
- **Print report** — one page aggregating every room's redesign + spec.

## Run it locally

```bash
npm install
cp .env.example .env     # add your RentCast key (image gen needs no key)
npm start
# open http://localhost:4178
```

## Keys

Image generation is **keyless**. Only the address lookup needs a key:

| Variable | Purpose | Where to get it |
|----------|---------|-----------------|
| `RENTCAST_API_KEY` | House facts by address | RentCast free tier (~50/mo) — https://app.rentcast.io |

`PROPERTY_API_KEY` is accepted as a fallback name; `RENTCAST_API_HOST` defaults to
`api.rentcast.io`. (Without a key, the app still runs and generates redesigns —
only "Fetch facts" is disabled.)

To use a paid generation provider instead of Pollinations (e.g. fal.ai, Replicate,
OpenAI gpt-image, BFL Flux Kontext), add a server adapter + its key and swap the
`runGeneration` call in `public/app.js`.

## Deploying (Vercel)

The repo is set up for Vercel (`api/index.js` + `vercel.json`). Pushes to the
production branch (`main`) auto-deploy. Set `RENTCAST_API_KEY` under **Project →
Settings → Environment Variables** (Production) for address lookup; image
generation works with no configuration.
