# 11505 Old Creedmoor Rd, Raleigh NC 27613 — Room Redesigns

Source listing photos live in `rooms/_source/`.
AI room redesigns are generated per room and saved under `designs/<room>/`.

## Workflow
1. Drop original listing photos into `rooms/_source/`.
2. Tag each photo by room.
3. Generate redesign concepts per room (Pixa image generator).
4. Save outputs to `designs/<room>/` and review.
